Manage notes from your terminal or coding agent.

Sign in once with a personal API token, then push, pull, search, and read review comments on hosted notes. Every command supports --json and accepts full pasted URLs.

Host a server CLI reference

Sign in with any pasted URL

Create a 90-day token under API tokens in your account menu on the hosted site. Run aniflow login and paste any URL from the site (a note, /files/, /tokens, or just the host). aniflow strips it to the server base, verifies the token, learns your default folder and shared folders, and saves ~/.config/aniflow/config.json with mode 0600.

Tokens are stored only as SHA-256 hashes on the server and carry the exact same folder permissions as your browser session.

# install the CLI
uv tool install git+https://github.com/chmouel/aniflow

# paste any page URL; prompts for the API token
aniflow login https://notes.example.com/pub/files/team/plan.md

# check active account, default folder and shared folders
aniflow whoami --json

Push, pull, search and review

Pass shorthand paths like plan.md (goes into your folder), team/plan.md (goes into a shared folder), or paste a full browser URL straight into pull, push, comments, ls, or rm.

When editing an existing note from a script or agent, pull with --json to grab its version and pass --if-match on push so a concurrent edit is never overwritten.

# list and search
aniflow ls                                 # your folder
aniflow ls /                               # all folders
aniflow search "kueue"                     # filenames + content

# upload, download, update safely, delete
aniflow push plan.md                       # -> <login>/plan.md
aniflow push plan.md team/plan.md
cat draft.md | aniflow push - team/draft.md --json

ver=$(aniflow pull team/plan.md --json | jq -r .version)
aniflow push plan.md team/plan.md --if-match "$ver"

# read review comments as an agent-ready prompt
aniflow comments team/plan.md
aniflow rm team/old.md

Bundled coding-agent skills

aniflow ships two skills inside the package: aniflow-diagrams (writing animated Mermaid walkthroughs and slide decks) and aniflow-notes (using the CLI above to publish, search, edit, and address review comments).

Install them into ~/.agents/skills, ~/.claude/skills, or the current project with one command. Existing symlinks are left untouched so local dev checkouts stay intact.

# list bundled skills and install status
aniflow skill list

# install or update all bundled skills
aniflow skill install                      # ~/.agents/skills
aniflow skill install --claude             # ~/.claude/skills
aniflow skill install --project            # ./.agents/skills

# print or remove one
aniflow skill show aniflow-notes
aniflow skill remove aniflow-notes
